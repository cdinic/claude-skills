# Claude skills

Skills I use across Claude chat, Projects, and Claude Code.

## be-ambitious

Turns a task or prompt into the deeper version a top expert would ask for. Deeper, not bigger. Based on Felix Rieseberg's [How to be more ambitious: A tutorial for humans with models](https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/).

Trigger with `/be-ambitious` or "make this prompt deeper."

## Install

**Claude Code:** copy the skill folder into your skills directory.

```
mkdir -p ~/.claude/skills
cp -r be-ambitious ~/.claude/skills/
```

**Claude chat:** zip the `be-ambitious` folder and upload it in Claude's Skills settings.
